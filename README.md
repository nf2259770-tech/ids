# Nikita — portfolio

Готовый адаптивный сайт-портфолио на обычных HTML, CSS и JavaScript. Сборка и установка зависимостей не нужны.

## Запуск

Откройте `index.html` в браузере. Если видео не запускается при открытии файла напрямую, запустите папку через любой локальный веб-сервер или опубликуйте её на GitHub Pages.

## Публикация на GitHub Pages

1. Создайте пустой репозиторий на GitHub.
2. Загрузите **содержимое** этой папки в корень репозитория: `index.html`, `styles.css`, `script.js`, `README.md` и каталог `assets`.
3. В GitHub откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, затем нажмите **Save**.
5. После завершения публикации GitHub покажет ссылку на сайт в этом же разделе.

Можно загрузить проект через GitHub Desktop: добавьте папку репозитория, скопируйте в неё файлы сайта, затем нажмите **Commit to main** и **Push origin**.

## Что внутри

- Отдельный титульный экран и профиль с портретом.
- Карусель из 11 видео: перетаскивание, стрелки, крупное воспроизведение со звуком и управлением.
- Композиция из оригинальных постеров и объектов: наведение слегка увеличивает работу, нажатие открывает её по центру с кнопкой закрытия.
- Папки `Vinyl Russia`, `SABU` и `MIRAVI` ведут на отдельные страницы кейсов.
- В кейсе Vinyl Russia — вертикальный Reels с мероприятия и горизонтальная презентация дилерского центра РОЛЬФ с отдельными описаниями.
- Контактный экран с быстрыми ссылками и копированием email.
- Медленные декоративные анимации и адаптация под телефон.

## Файлы для правок

- `index.html` — текст, ссылки, порядок секций и состав видео.
- `styles.css` — цвета, сетка, шрифты, анимации и адаптивность.
- `script.js` — поведение карусели, видеоплеера, просмотра постеров и копирования email.
- `assets/videos/` — веб-копии роликов в MP4/H.264.
- `assets/thumbs/` — обложки для карусели.
- `assets/posters/` — графика из макета Figma.
- `assets/user-art/` — веб-копии постеров и макеты объектов с прозрачностью, загруженные владельцем сайта.
- `assets/folder-covers/` — иллюстрированные обложки папок по присланному скриншоту из Figma.
- `assets/nikita-face.png` — исходный портрет для профиля.

Видео подготовлены для веба, исходные файлы на компьютере не изменялись. Для загрузки точных гарнитур `ZCOOL KuaiLe`, `Ubuntu`, `Englebert`, `Lalezar`, `Simonetta`, `Ole` и `FigmaHand` нужен интернет; `Signika Negative SC` уже находится в папке `assets/fonts/`.
